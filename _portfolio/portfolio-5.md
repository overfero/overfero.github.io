## REST API for Ngambis App

This project focuses on developing a REST API for the Ngambis App, which provides functionality for managing projects and users. The API is built using modern technologies to ensure efficient performance and scalability.

### Tech Stack
- **Backend Framework**: Ktor
- **Data Serialization**: Gson
- **Database**: MongoDB

### Features
- **Project Management**:
  - Add project
  - Remove project
  - Update project
  - Read project

- **User Management**:
  - Add user
  - Remove user
  - Update user
  - Read user
