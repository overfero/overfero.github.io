## Cyberbullying Detection

A machine learning model to detect cyberbullying.<br/>
<img src='/images/cyberbullying_detection.png'>

This project involves developing a machine learning model to detect cyberbullying. The project employs end-to-end machine learning practices including distributed computing, data versioning, model versioning, and distributed dataset on the Google Cloud Platform. Following industry best practices, it simplifies deployment. The machine learning model is deployed as a REST API using FastAPI.

[GitHub Repository](https://github.com/overfero/overfero-model)
